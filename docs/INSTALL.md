# Dataverse for Claude — Quick Install

**A 5-minute install guide. For background on how it works, what it does, and the security model, see [CLIENT_OVERVIEW.md](CLIENT_OVERVIEW.md).**

---

## Before you start

You need three things on your Windows PC:

| | What | How to get it |
|---|---|---|
| 1 | **Node.js v20 or later** | Download the **LTS** installer from <https://nodejs.org>. Default options. Restart PowerShell after installing. |
| 2 | **Claude Desktop** | Download from <https://claude.ai/download>. Sign in with your work account. |
| 3 | **The client secret** | Ask Ivan (MS Cloud Experts). You'll paste it once during install. |

To confirm Node is ready, open **PowerShell** and run:

```powershell
node --version
```

You should see `v20.x.x` or higher. If you see an error or an older version, install Node first.

---

## Install

### Step 1 — Open PowerShell

Start menu → type `PowerShell` → Enter. Normal user is fine, no Admin needed.

### Step 2 — Paste this one line and press Enter

```powershell
irm https://raw.githubusercontent.com/MS-Cloud-Experts/mcp-business-central/main/setup-dataverse.ps1 | iex
```

### Step 3 — Answer the wizard prompts

When the installer reaches this point, it opens a small **PowerShell wizard** that asks you for four values in sequence:

![PowerShell wizard prompts](images/wizard-prompts.png)

| Prompt | Where to get the value |
|---|---|
| **Environment URL** | Your Dataverse environment URL — e.g. `https://orga7f42fb6.crm.dynamics.com`. Provided by your IT admin (or by MS Cloud Experts during onboarding). |
| **Tenant ID** | The GUID of your Microsoft 365 tenant. Provided by your IT admin. |
| **Client ID** | The GUID of the Azure app registration used by the MCP. Provided by your IT admin. |
| **Client Secret** | Either provided by your IT admin, **or** generated by you directly in Azure — see [CLIENT_OVERVIEW.md → Managing the client secret](CLIENT_OVERVIEW.md#managing-the-client-secret--two-paths) for the self-serve path. |

**Input for the secret is hidden** — you won't see what you paste. That's normal. Right-click to paste, then press Enter.

The installer then prints 4 steps as it runs (install package → write config → update Claude config → verify). Total time: 30 seconds to 2 minutes. When you see the green **INSTALLATION COMPLETE** banner, move on.

### Step 4 — Fully quit and reopen Claude Desktop

- Right-click the Claude icon in the system tray (bottom-right, near the clock) → **Quit**.
- Reopen Claude Desktop from the Start menu.

> **Don't just close the window** — Claude keeps running in the tray. Without a full quit, it won't pick up the new MCP server.

### Step 5 — Confirm it worked

Look at the bottom of the Claude chat input. You should see a **hammer icon** with around **79 tools**. Click it and confirm the list starts with `dataverse_...`.

Open a new chat and ask:

> *"Use the Dataverse whoami tool and tell me which environment I'm connected to."*

If you get back an environment URL and a user ID, **you're done**. Start using it.

## If something goes wrong

| Symptom | Try this first |
|---|---|
| No hammer icon, or 0 tools | Make sure you fully quit Claude (tray → Quit), not just closed the window. Reopen. |
| `'node' is not recognized` | Node.js isn't installed or PowerShell wasn't restarted after installing it. Close and reopen PowerShell. |
| `Cannot find module ...` with a different username | The installer ran as a different Windows user. Sign in as the user who'll use Claude, then re-run. |
| `Authentication failed` / `401` errors | The client secret expired or is wrong. Ask Ivan for a fresh one and re-run the installer. |
| Anything else | Send Ivan a screenshot of the error message and the installer's last few lines. |

> **Note:** the client secret is stored in `%USERPROFILE%\mcp-dataverse\config.json`, **not** in `%APPDATA%\Claude\claude_desktop_config.json`. If you peek at the Claude config and don't see the secret — that's correct, by design.

For the full troubleshooting list, security details, and capability catalog, see [CLIENT_OVERVIEW.md](CLIENT_OVERVIEW.md).

## A note on Power Platform Admin Center

If you or your admin sees any "MCP" settings in **Power Platform Admin Center** — a *Managed Environment* toggle, a *Dataverse Model Context Protocol* feature flag, or an *Allowed MCP Clients* table — **those are unrelated to this installer.**

This installer uses the **standard Dataverse Web API** (`/api/data/v9.2/`), not Microsoft's native MCP endpoint. Whatever those PPAC settings are doing (or not doing), this integration does not depend on them. They can be left on, turned off, or cleaned up at your team's discretion — none of that affects the Claude Desktop ↔ Dataverse connection set up by this guide.

If you want the full explanation of why two different endpoints exist and which one we use, see [CLIENT_OVERVIEW.md Section 4](CLIENT_OVERVIEW.md#4-authentication--permissions).

## Updating later

To pull the latest version of the Dataverse package (new tools, bug fixes), just re-run the same one-liner from Step 2. It reinstalls in place and picks up the latest version from npm.

When the client secret expires (typically every 6–24 months), Claude starts returning authentication errors. Ask Ivan for a new secret and re-run the installer.
